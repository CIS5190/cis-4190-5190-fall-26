# CIS 4190/5190: Applied Machine Learning — Fall 2026

Public repository of student-facing course materials.

## Homework

| | Points |
|---|---|
| [HW0](hw0/) | 65 (50 autograded + 15 written) |

**Deadlines are on the [course schedule](https://www.engineering.upenn.edu/~cis5190/fall2026/schedule.html)
and in Gradescope** — those are authoritative, and deliberately not repeated here.

Open a homework notebook in Colab, then **File → Save a Copy in Drive** before
you start — the copy in this repository is a read-only master.

Each notebook contains its own PennGrader cells: running a grading cell submits
that answer and records your score immediately. You may resubmit up to 100 times
per day per test case, and only your best score counts. When you are finished,
download the notebook (`File → Download → Download .ipynb`) and upload it to
Gradescope before the deadline so your score can be collected.

## Getting up to speed

If you would like to review the prerequisites, the course

has primers written for this course. The
[Python, numpy and pandas primer](https://www.engineering.upenn.edu/~cis5190/fall2026/docs/basics_python_numpy.ipynb)
covers everything HW0 uses.
